SwiftVM guest tools for Windows

They let SwiftVM on the Mac see the version and addresses of this machine, set its clock after it
was suspended, shut it down, share the clipboard, run commands with swiftvm exec, and make the display
follow the window.

To install them, plug in the virtio-win disc too (SwiftVM does when it plugs in this one), then run
install.cmd on this disc. It asks to run as an administrator.

What the agent does is written to C:\ProgramData\SwiftVM\agent.log.
