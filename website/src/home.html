What SwiftVM does

Guests that set themselves up, and everything you need to work with them.

macOS guests

SwiftVM installs macOS from Apple and, from macOS 27 on, sets it up for you. No setup assistant to click through.

Linux guests

Ubuntu and Debian from a ready-made image, ready in seconds. Or install another ARM64 distribution from its installer disc.

SSH by name

Every machine gets an SSH name. Run ssh web-server from your Mac, without looking up addresses.

Snapshots and duplicates

Keep a machine exactly as it is, and come back to it later. A duplicate takes no time and no extra space at first.

Suspend and resume

Save a machine's memory to disk and free your Mac's. It continues where it was the next time you start it.

Shared folders and clipboard

Open folders of your Mac in the guest, and copy and paste between the two.

Networking

Each machine has its own address, the same every time it starts. Forward ports to reach what runs in a guest.

USB devices and disk images

Hand a drive, a security key, or a serial adapter to a running guest. Plug in disc and disk images as USB drives.

Command line

swiftvm does from a terminal what the app does from the menu bar, so everything can be scripted.

Or drive it from a terminal

The app owns the machines and swiftvm drives the app, so the panel and the terminal never disagree.

Every command

zsh
% swiftvm create ubuntu-26.04 --name "Web Server"
% swiftvm share web-server ~/Projects
% swiftvm forward web-server 8080:80
% swiftvm snapshot web-server "Before upgrade"
% swiftvm ssh web-server

How it is built

Nothing runs as root

Apple's Virtualization framework runs each guest in the app's own process. There is no helper and no kernel extension.

A machine is a folder

Its settings, disk, firmware, and snapshots live in one .swiftvm package. Copies and snapshots are APFS clones of its files.

Open source

Written in Swift and released under the Apache-2.0 license. Read the technical design, or build it yourself.
